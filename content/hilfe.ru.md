## Бесплатно

### Консультация для арендаторов в вашем районе (Mieterberatung)

В каждом районе Берлина есть открытые консультации для арендаторов, бесплатные для всех арендаторов района. В суде они вас не представляют. Список районов со ссылками есть у Сената:
<https://www.berlin.de/sen/wohnen/service/serviceadressen/mieterberatungen-in-den-bezirken/>

### Сервисный телефон по аренде Сената (Servicetelefon Miete)

(030) 90173 3860: для вопросов о берлинском Mietspiegel и об арендной плате. На вопросы арендного права отвечают консультации в районах.

### Mietpreisprüfstelle Berlin (служба проверки арендной платы)

Бесплатная первичная консультация земли Берлин для всех берлинских домохозяйств-арендаторов, если ваша арендная плата, возможно, слишком высокая, например из-за ограничения арендной платы (Mietpreisbremse). Только по записи. Информация также на английском языке.
<https://www.berlin.de/mietpreispruefstelle>

### Консультации на нескольких языках

В Центре приёма (Willkommenszentrum) Уполномоченной Сената по вопросам интеграции можно искать консультационные пункты по теме «Жильё» и по вашему языку:
<https://willkommenszentrum.berlin.de/ru/konsultacionnye-centry>

## Для арендаторов жилищных компаний земли Берлин

Служба омбудсмена для арендаторов жилищных компаний земли Берлин (Ombudsstelle für Mieterinnen und Mieter der landeseigenen Wohnungsunternehmen) отвечает за арендаторов degewo, GESOBAU, Gewobag, HOWOGE, STADT UND LAND, WBM и их дочерних компаний. В случае berlinovo она отвечает только за «классические» арендные квартиры, которые принадлежат самой berlinovo, а не за квартиры её фондовых компаний. Она консультирует на немецком и английском языках по соглашению о сотрудничестве (Kooperationsvereinbarung) и по обещанию доступности (Leistbarkeitsversprechen), но не по общим вопросам арендного права.
<https://www.ombud-lwu.de/>

## Общества арендаторов (Mietervereine, с членским взносом)

Общества арендаторов консультируют своих членов. Многие также предлагают страховку на расходы по судебному процессу. Перед вступлением спросите о размере взноса, условиях, сроках ожидания и минимальном сроке членства.

- Berliner Mieterverein: <https://www.berliner-mieterverein.de>
- Berliner MieterGemeinschaft: <https://www.bmgev.de>
- Mietervereinigung Berlin: <https://www.mietervereinigung-berlin.de>
- Mieterschutzbund Berlin: <https://www.mieterschutzbund-berlin.de>
- AMV (Alternativer Mieter- und Verbraucherschutzbund): <https://mieter-verbraucherschutz.berlin>

## Адвокаты

Для судебного процесса или проверки вашего конкретного случая есть адвокаты по арендному праву (Mietrecht). Без страховки юридической защиты (Rechtsschutzversicherung) это стоит денег. Если у вас мало денег, вы можете подать в участковый суд (Amtsgericht) заявление о помощи для консультации (Beratungshilfe, Beratungshilfegesetz). Для судебного процесса есть помощь в покрытии судебных расходов (Prozesskostenhilfe, § 114 ZPO). Если вы проиграете процесс, расходы арендодателя вам всё равно придётся оплатить (§ 123 ZPO).

Центр защиты прав потребителей Берлина (Verbraucherzentrale Berlin), по собственным данным, не консультирует по арендному праву.
